---
name: pr-check
description: 충돌 검사 — main과의 git 충돌, 같은 화면 경로, 다른 열린 PR·최근 머지와의 파일·기능 겹침을 찾고 해결 방법을 제안한다. make ship이 멈췄거나 "충돌 있나?" 확인할 때 사용.
---
1. 미커밋 변경이 있으면 알리고 커밋할지 묻는다 (검사는 커밋된 내용 기준).
2. `scripts/check-conflicts.sh` 실행 후 세 구역으로 요약한다.
3. **❌ git 충돌** — `make sync`로 main을 merge해 해결한다. 파일별 의도를 설명하고 해결안을 제시한다. 남의 기능·공용 파일이면 선택지를 주고 사용자에게 묻는다 (내 쪽 경로·이름 분리 / 상대 변경 위에 얹기 / 담당자와 상의).
4. **❌ 같은 경로** — 같은 화면 경로(`frontend/src/app/<route>/`)를 두 사람이 만들고 있다. 경로 분리 또는 한쪽으로 합치기를 사용자에게 묻는다. 경로를 바꾸면 메뉴·링크·계약의 사용처도 고친다. (마이그레이션은 시각 기반 이름이라 번호 충돌이 없다)
5. **⚠️ 겹침** — 다른 열린 PR과 같은 파일·기능이면 작성자를 알려 주고 먼저 ship할 쪽을 정하자고 제안한다. 머지 잠금이 순서를 보장하므로, 나중 쪽은 ship이 main을 다시 반영·검사한다. 공용 파일이면 변경을 최소화한다.
6. 해결했으면 다시 실행해 ❌가 없어질 때까지 반복하고 `make ship`을 다시 한다.
