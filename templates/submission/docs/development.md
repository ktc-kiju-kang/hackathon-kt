# Development — 개발 과정과 AI 활용

> 개발하는 동안 **계속** 쓴다. 나중에 기억으로 채우지 않는다.
> AI 사용 기록 원본은 kode:ton이 수집한다. 이 문서는 그중 **의미 있는 사례와 사람이 한 검증**을 짚어 준다.

## 1. 작업 방식
- 브랜치·PR: {{예: main 보호, 기능별 브랜치, PR 머지}}
- Issue: 주최 양식(개발 작업·검증), 제목에 `[REQ-xx]`, 근거(커밋·시험 결과)를 붙이고 **Close as completed**
- 검사: {{lint·테스트 명령, CI 여부}}
- 사용한 AI 도구: {{Claude Code / Copilot / …}} — 역할: {{예: Claude=구현·리뷰, Copilot=자동완성}}

## 3. AI 활용 기록
**AI가 한 것**과 **사람이 확인·수정한 것**을 구분한다. 틀린 답을 잡아낸 사례가 가장 중요한 근거다.
시작 키트에서는 `make record`가 머지된 PR마다 한 행을 붙인다 (AI 리뷰 점수, 리뷰가 지적해 고쳐진 것, 머지한 사람 — `scripts/dev_log.py`). PR 본문 "## 변경 내용"의 `- AI 검증: …` 줄은 "사람이 확인한 방법" 칸에 옮겨진다 — 사람이 직접 본 것(화면·수동 TC·고친 이유)은 거기에 적는다. 이 표를 손으로 고치지 않는다 (여럿이 고치면 충돌).

| # | 작업 | AI가 한 것 | 사람이 확인한 방법 | 고친 것 (없으면 "없음") | 근거 |
|---|---|---|---|---|---|
| 1 | {{REQ-01 API 구현}} | {{초안 코드 생성}} | {{TC-01-3 실행 — 타인 자료가 조회됨}} | {{소유자 조건 추가}} | {{커밋 SHA}} |
