## 6. REQ별 코드 위치
평가자가 요구사항에서 코드로 바로 갈 수 있게 한다. 경로는 저장소 기준 상대 경로.
**REQ마다 블록 하나**를 기획 때 미리 만들어 두고, 담당자는 자기 블록만 고친다 (블록 사이에 빈 줄과 제목이 있어 여럿이 동시에 고쳐도 git 충돌이 나지 않는다). 역할 분담이면 BE는 백엔드 줄, FE는 프론트 줄만 고친다 — 줄 사이 빈 줄이 있어야 둘이 동시에 고쳐도 충돌하지 않는다.

### REQ-01
- 프론트: `{{frontend/src/…}}`

- 백엔드: `{{backend/app/…}}`

- 시험: TC-01-1~3 (`{{backend/tests/…}}`, `{{e2e/…}}`)
