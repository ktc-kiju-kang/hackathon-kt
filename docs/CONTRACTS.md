# 인터페이스 계약 (Single Source of Truth)

> 팀원 간 경계가 되는 API / 타입 / 스키마를 여기 정의한다. 구현보다 **계약이 먼저** 머지된다.
> 변경 시: 버전 올리고, 변경 이력에 기록, 영향받는 owner에게 알림.
