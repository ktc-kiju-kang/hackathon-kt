# REQ-02 24시간 넘게 열린 PR 강조

> 인덱스: [prd.md](../prd.md) — 상태·Issue는 인덱스 표에서 관리한다. 이 파일은 REQ-02의 근거와 확인 조건(AC)의 원본이다.

## 근거 원문
- SRC-02: "24시간 넘게 열린 PR은 눈에 띄게 알려 주면 좋겠다."

## 설명
- 관련 흐름: FLOW-01 ([experience.md](../experience.md))

누가: 현황판(`/dashboard`)을 보는 팀원. 무엇을: "열린 PR" 목록에서 열린 지 24시간이 넘은 PR이 다른 PR과 구별되게 강조되어 보인다. 왜: 반나절 넘게 열린 브랜치를 빨리 찾아 정리하기 위해.

REQ-01의 "PR이 열린 시각"을 쓰므로 REQ-01 다음에 머지한다. 새 API AC는 없고 화면 AC만 있다. 기존 현황판의 "24시간 넘은 선점 경고"(팀원별 칸)와는 별개다.

범위 안: 목록에 보이는 열린 PR(초안 포함, Q4)의 화면 안 강조. 범위 밖: 브라우저 푸시·메신저 등 화면 밖 알림(Q6, 인덱스 "범위 밖").

## 확인 조건 (AC)

| AC | 조건 | 종류 | 확인 | 시험 |
|---|---|---|---|---|
| AC-02-1 | 열린 지 24시간이 넘은 PR 줄은 경고 표시와 "24시간 넘음" 같은 문구로 다른 PR과 구별되어 보인다 — 색만으로 구별하지 않는다 (Q6) | 정상 | 화면 | TC-02-1 |
| AC-02-2 | 열린 지 24시간이 넘지 않은 PR(정확히 24시간 포함)은 강조 표시 없이 보인다 | 경계 | 화면 | TC-02-2 |
| AC-02-3 | 초안 PR도 열린 지 24시간이 넘으면 같은 강조 표시가 보인다 (Q4) | 경계 | 화면 | TC-02-3 |

## 가정·질문
- Q1 기준 시각은 화면을 보는 현재 시각 — 가정 (AC-02-1, AC-02-2의 경과 판단)
- Q4 초안 PR 포함 — 가정 (AC-02-3)
- Q6 "눈에 띄게"는 화면 안 경고 표시 + 문구, 화면 밖 알림은 하지 않음 — 가정 (AC-02-1)
- "24시간 넘게"는 원문 그대로 24시간 초과로 읽는다 (정확히 24시간은 강조하지 않음, AC-02-2)
