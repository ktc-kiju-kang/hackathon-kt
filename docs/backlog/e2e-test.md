# E2E Test — 현황판 열린 PR 경과 시간 (시험 목록)

> 시나리오는 구현 **전에** 쓴다(상태 `미실행`). 결과는 직접 실행한 뒤 채운다. 정의서: [prd.md](prd.md)

### TC-01-1 열린 PR마다 열린 시각·업데이트 시각이 응답에 있다 (AC-01-1)
- **GIVEN** GitHub 레포에 열린 PR이 2개 있다 (그중 1개는 초안)
- **WHEN** 현황판의 GitHub 현황 API를 부른다
- **THEN** 응답의 열린 PR 2개 각각에 PR이 열린 시각과 마지막 업데이트 시각이 있다
- **AND** 두 값이 GitHub에 기록된 그 PR의 열린 시각·업데이트 시각과 같다

### TC-01-2 PR 줄마다 경과 시간이 보인다 (AC-01-2)
- **GIVEN** 열린 지 30분, 5시간, 2일 3시간 된 열린 PR이 하나씩 있다
- **WHEN** 현황판(`/dashboard`)을 연다
- **THEN** "열린 PR" 목록의 세 줄에 각각 "30분", "5시간", "2일 3시간"이 보인다

### TC-01-3 PR 줄마다 마지막 업데이트 시각이 보인다 (AC-01-3)
- **GIVEN** 마지막 업데이트 시각이 2026-10-09 14:05 KST인 열린 PR이 있다
- **WHEN** 현황판을 연다
- **THEN** 그 PR 줄에 "10-09 14:05"가 보인다

### TC-01-4 GitHub 현황 실패 시 오류 안내 (AC-01-4)
- **GIVEN** GitHub 현황을 불러오지 못하는 상태다 (예: 레포를 알 수 없거나 GitHub 응답 실패)
- **WHEN** 현황판을 연다
- **THEN** 열린 PR 칸에 경과·업데이트 시각 없이 오류 안내가 보인다
- **AND** 서버·시험 기록 등 현황판의 다른 칸은 그대로 보인다

### TC-02-1 24시간 넘게 열린 PR 강조 (AC-02-1)
- **GIVEN** 열린 지 25시간 된 PR과 3시간 된 PR이 있다
- **WHEN** 현황판을 연다
- **THEN** 25시간 된 PR 줄에만 경고 표시와 "24시간 넘음" 같은 문구가 보인다
- **AND** 문구가 있어 색을 구별하지 못해도 강조를 알 수 있다

### TC-02-2 24시간 이하 PR은 강조하지 않는다 (AC-02-2)
- **GIVEN** 열린 지 정확히 24시간 된 PR과 23시간 59분 된 PR이 있다
- **WHEN** 현황판을 연다
- **THEN** 두 PR 줄 모두 강조 표시·문구 없이 보인다

### TC-02-3 초안 PR도 같은 기준으로 강조 (AC-02-3)
- **GIVEN** 열린 지 30시간 된 초안 PR이 있다
- **WHEN** 현황판을 연다
- **THEN** 그 PR 줄에 초안 표시와 함께 24시간 넘음 강조 표시가 보인다
