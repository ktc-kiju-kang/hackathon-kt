# 0001. 프론트엔드 UI: shadcn/ui

- 상태: 채택
- 날짜: 2026-10-01

## 배경
해커톤 기간 내 3명이 일관된 UI를 빠르게 만들어야 한다.

## 결정
`web/`에 Vite + React + TS + Tailwind v4 + shadcn/ui(radix 기반, nova 프리셋, lucide 아이콘)를 사용한다.

## 결과 / 트레이드오프
- 컴포넌트 코드가 레포에 복사되므로 자유롭게 수정 가능하지만, 업스트림 업데이트는 수동 반영.
- 팀원 모두 같은 디자인 토큰(`src/index.css`)을 공유 → 화면 간 일관성 확보.
