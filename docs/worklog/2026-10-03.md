## 정한 것 (결정)
- **규칙은 `@import`가 아니라 `.claude/rules/`의 `paths:`로 나눈다.** `@import`는 세션 시작 시 항상 펼쳐져 토큰이 줄지 않고, `paths:`만 해당 경로 파일을 다룰 때 지연 로드된다 (실제 세션에서 동작 확인).
- **자동 강제와 관례를 구분해 쓴다.** 도구가 막지 않는 것을 막는다고 쓰지 않고, 없는 것은 `docs/SDLC.md`에 한계로 적는다.
- **Vitest는 4.x.** 5.x는 Node 22.12+를 요구하고 CI는 Node 20이다. CI Node를 올리면 `deploy.yml`까지 건드려 범위가 커진다.
- **비밀값 스캔의 `.env.example` 예외는 규칙 1개×경로 1개로만** 둔다. 파일 통째 예외는 지난번 사고(정체불명 53자 값)를 막으려는 목적에 어긋난다.

## 확인한 사실
- `main` 보호: 필수 상태 체크 `frontend`·`backend`(비관리자에게 강제), 승인 리뷰 필수 아님, 관리자는 우회 가능. 이 계정은 관리자가 아니다.
- `gitleaks-action` v3: 개인 계정 저장소는 라이선스 키가 필요 없다 (조직으로 옮기면 필요) — 공식 README 기준이고, 이 저장소 소유자 유형은 `User`임을 API로 확인했다.
- pip 생태계의 Dependabot은 `requirements.txt`뿐 아니라 `requirements-dev.txt`도 읽는다 (`pytest` PR로 확인).
